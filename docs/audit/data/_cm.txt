audit(d3): per-source inventory validator (quantifies partial deliveries)

Judging one delivered D3 inventory against the gates that will actually decide
whether it can be assembled, without needing all seven sources present. It
reports mechanisms, verified count, missing evidence, module coverage resolved
through the pattern matcher, hint corrections and absent domains, then says
plainly whether the source PASSES or would block assembly.

It exists because "an agent delivered a file" and "an agent delivered something
assemblable" are different claims, and only the second matters. Measured result
at the time of writing:

  grok      23 mechanisms, 23/23 verified, 0 missing evidence
            BUT 0/82 modules accounted for, 7 domains empty -> FAILS
  opencode   0 mechanisms, empty stub                          -> FAILS

Both are partial drafts, not inventories.
