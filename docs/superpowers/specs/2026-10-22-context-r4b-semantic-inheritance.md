## Decisions selected by root

1. A semantic seed is a new explicit representation of the effective ordered conversation, distinct from raw structural export. Preserve the existing raw remapper/proof guarantees. Do not clone the complete parent archive and remove fields afterward; read the existing central structural history/projector and capture only selected effective payloads, source observations and exact result dependencies.
2. Use next unused Session format11, a closed semantic-seed codec1, explicit inherited-prefix metadata and non-ignorable bootstrap records. Actual format10 execution readers must refuse new ready and interrupted/header-only documents before repair/auth/dispatch. Product version stays0.1.13-rc.1. Current old-format/legacy semantics remain readable without fabricated bootstrap certificates.
3. Store semantic inheritance as dedicated `conversation/seed-group` records, one per complete source/evidence-connected interval, plus explicit omitted-parent-work observations. Each group contains ordered typed input/summary/exchange items and their LLM message bundles. Integrate these records into the ONE core-session history/projector; never manufacture local successful tool results, physical attempts or response acceptance merely to make a raw-log projector accept flattened messages.
4. Target creation uses the original coordinator/managed registry and immutable header reservation followed by deterministic seed and completion batches, as the preferred bootstrap proposal. Unprepared cached empty views explicitly refuse; same-operation cached reentry joins/reconciles the existing owner. An incomplete cold target requires exact original payload and current authorization, or returns durable/discoverable payload-required. No new random child, destructive rollback, changed-source reconstruction under the old digest, second writer/map/store, or blanket catch-and-ignore.
5. Use the **live-attestation-only native variant**. Do not add archived full execution/credential continuity tuples merely for explanation. Archived seed native bytes and original source/digest are observations; genuine source proof is a private association with actual accepted objects and the original successful owned physical receipt, in the existing Agent execution owner. Cold/legacy/detached copies cannot reconstruct this capability. Exact same-live-binding target transfer remains possible; unverified data uses its real portable representation or blocks if opaque-only.
6. The native fence concerns the actual captured credential used by transport, plus existing current-source/target/Stop checks. It does not introduce logout linearizability or a revocable account lease. Codex's captured token/account/epoch remains paired with final request identity/headers; require the inherited-native comparison in final prepared execution, before the existing confirmation callback/receipt and issue/fetch, independent of calibration. The candidate retains/authorizes constraints; it does not invoke them a second time. Do not turn mismatched native data into compatible data via the existing identity handoff.
7. R4A artifact refs/catalogs/members are confirmed through their existing owner with exact revision/digest and target pin/ACL evidence, before target ready. A path, parsed ref, void legacy grant or copied receipt supplies no authority. Catalog membership is processed with bounded metadata pages, never original result body reads. Source/export inspection remains auth/model-free.

## Semantic grouping, source selection and provenance

Use the current core history/index to determine visibility, accepted/legacy/unresolved units, replacement insertion order, monotone consumption, typed input/media companions and native ordering. The interval-union rule currently in context-engine/reduction/selection.ts closes shared source/evidence/physical-unit intervals. A narrow shared pure closure primitive may be factored for the existing reduction caller and the new seed selector; do not create a second divergent grouping rule or carry token pricing/protection policy into inheritance selection.

For a complete selected interval, preserve item order, item kinds, original source observations and all typed messages. Each target seed group's items receive target-local source addresses such as `(seedGroupSeq, item:<ordinal>)`, plus a shared local group address. These local addresses participate in future summary/replacement coverage. Original parent/detached coordinates remain lineage observations, not foreign local addresses or child execution permissions. Sharing the group address makes partial selection fail the existing coverage intersection rule. The pure structural index stores metadata/recipes only, not another payload/LLM-message array; payload rendering reads the seed record just as it reads other archive recipes.

An in-flight/effect-unknown **exchange interval** is excluded as a whole, including parallel calls, partial results and tool-media companions. Emit observation metadata with original unit/source identity, as-of digest, open/unresolved state and scalar call counts; no invented result or wait obligation enters wire messages. Independently sourced user/host-input items must remain available: preserve their complete input/derived-context evidence component as a low-authority input-observation group, explicitly record its relationship to the omitted parent unit, and do not relabel that parent unit closed. Inputs must not smuggle partial tool results through this exception. The new delegated task remains a distinct child-local admitted input after the seed prefix.

Preserve none/all/N/completed-boundary selection honestly. None produces no inherited conversation and does not remove current child role/host instructions. Resolve the original turn boundaries structurally, including preexisting inherited turn metadata; retain scalar semantic turn counts/ranges so later forks of a child do not collapse inherited history into an unframed pseudo-turn. Seed items/groups carry validated turn ranges; local real turns follow the inherited range. A summary spanning the requested N/completed boundary is inseparable: refuse rather than widening the selection or reviving consumed source bodies. An unframed legacy source remains explicitly unframed, preserving the existing no-turn-start/all fallback. Empty/hidden turns may contribute to the requested source boundary without generating wire content.

Selection uses current effective content and current monotone rewrite/branch visibility. A later effective summary may represent source turns inside the requested completed boundary; include it only when its entire covered turn extent belongs to the selection. Coverage that straddles the requested boundary refuses. Do not recreate discarded raw content just because an earlier atSeq was requested. The separate raw structural export remains available under its original contract.

The semantic source union is owned-session lineage or anonymous detached content with a content digest. An anonymous import gets no invented parentSession/source session ID. Prepared human/host-context relationships are typed semantic input relationships, not copied operational admission/preparation claims. With dedicated seed groups, no inherited raw admission/action/attempt fact is needed; anonymous seed scope is explicit in the new header/validator and never relies on a fake parent identity. Original scopes/producers remain observations; projected authority is inherited/observation. No calibration, execution receipt, permission or action allowance is imported.

Result wire text alone is not a complete dependency manifest. Collect selected genuine ResultEnvelope retention refs and dependency catalog refs from source evidence, with original source/document provenance; include unavailable retention truthfully. Required durable refs without actual source authority block bootstrap. Exact refs are copied, not retrieved wholesale or recaptured under fabricated result ownership. Legacy inline results retain their actual projected representation; this is not a claim that an active unpruned100MiB legacy result fits a model.

## Private live native flow and request boundaries

The original execution owner associates actual immutable accepted assistant/acceptance objects and original assistant/native/call digests with its successful owned physical receipt. It binds a completed unit digest only at a later history-backed lookup after actual results/media exist. This can be a WeakMap of receipt scalars/proof, without duplicated bodies or a durable account registry. Only a real successful accepted physical result mints it; pre-issue confirmation, failed audit text, copied JSON, custom injected stream and cold replay do not. Source attestation is a pure lookup. A legitimate warm inheritance hop can forward the original proof for unchanged bytes through host-only seed runtime state; a compiler never remints it from serialized fields.

The actual provider-runtime binding supplies the target transfer port. Arbitrary ModelClient.executionIdentity data does not substitute for binding-owned provenance. Target constraints are host callbacks/private capabilities kept outside serialized messages and outside the seed digest. They bind exact selected unit/message digests, actual target binding/route/model and source proof. Child Agent composition retains them for live inherited units; cold reopen has no such grants and explicitly uses portable data or reports opaque incompatibility.

The prepared request carries only a closed data plan for inherited units (unit identity, exact source-message indexes/digests, native-candidate or portable rendering). Each adapter owns lowering and returns per-unit final preservation/disposition facts tied to the prepared payload. Do not reinterpret aggregate native=unverified as proof that a particular unit was dropped or preserved. Existing wrappers/withOutputCap must preserve/rederive the data plan and final report through actual owner paths. Source proof and final issue callbacks are not serialized or deep-cloned through request wrappers.

Protocol selection is monotone: native-candidate may become portable, never the reverse within this preparation. Reprepare all currently refused portable-capable units together; each iteration strictly removes at least one native candidate and is bounded by nativeUnitCount+1 and the original action deadline. Protocol-specific prefix dependency can downgrade later affected units in the same pass. Opaque-only refusal terminates before issue. No provider request/count/auth is performed by this pure preparation loop and no action/attempt allowance is reset. A final actual-credential mismatch permits only the existing bounded unsent/unobserved rebuild with newly measured portable rendering under the same logical action; never alter bytes after measurement or reissue tools. An already-issued/observed request cannot take that path.

Keep normal existing main/local/cold native replay behavior separate. The new transfer plan constrains only inherited semantic units. Responses public/subscription remain separate routes; Anthropic may reject even same binding because fresh child system/tools alter the signed prefix; Gemini retains exact part/call/signature ordering. Bedrock ambient credential continuity is presently unavailable: retain its native source observations but portable-downgrade or block opaque-only inherited transfer, never claim same SDK object as credential proof. Actual first child request always includes fresh role/current host instructions, delegated task, tools, media and raw route options through the shared admission owner.

## Bootstrap contract and real consumers

Adopt the bootstrap-preflight proposal's closed target/request/outcome vocabulary: new, exact uncached-existing-empty and same-operation resume; ready/already-ready, not-issued, blocked with original token/phase, and explicit conflict/nonempty/cached-unprepared/wrong-view/incompatible/manifest-invalid refusal. Manifest binds stable operation/target identity, original creation metadata, source selection revision/digest, codec/version, exact compiled seed bytes/count, dependency digest and initial delegated-input identity/digest. Runtime guards are host-only and recheck source/instructions/Stop immediately before fixed-byte issue with no intervening await.

Extend existing backend create/header handling narrowly with qualified issue/reconcile. It must distinguish absent/committed/unknown/conflict and preserve unrelated existing metadata, while new target create cannot replace another target. Reentry reuses original creation timestamp/bytes. Header metadata must survive actual parse/buildSession/view capture. No ordinary updateMeta→open atomic claim. The managed document uses the existing pending/quarantine/queue/lease for isolated deterministic seed and completion batches; ordinary sources/actions/snapshots must not treat incomplete bootstrap as ready. Cold open recognizes incomplete bootstrap before ordinary repair.

Completion is a non-ignorable marker plus optional deterministic delegated input in one fixed batch after seed and exact dependency confirmation. Empty seeds do not emit an empty fact frame. Initial generation consumes the committed bootstrap input/seq, never admits a duplicate. Ready does not authorize replaying an already launched/unknown initial action. Parent current call/task identity must qualify the spawn operation; public fork/import calls mint one token per invocation and expose that same token/target on uncertainty. A retry must explicitly adopt it, not silently create a new random child.

Actual consumers to switch coherently: subagent managed and standalone none/all/N; team fresh/fork through the same child owner; persistence completed-prefix fork; SDK server/client and CLI/Gateway fork callbacks; explicit detached executor import before normal open. Preserve exact supplied-owned-view attachment. Retire semantic use of raw full-log cloning, random retry create and legacy inherited ref grants; retain raw structural export and truthful legacy compatibility where actually consumed. Standalone remains explicitly nondurable and must not silently instantiate a durable coordinator.

## Required independent qualification

- Literal semantic-group order, user/plugin/summary provenance, typed media/call/result closure, local coverage/compaction and nested fork turn boundaries; no whole archive clone. Use independent expected message bodies, not compiler output as expected input.
- Genuine managed and standalone spawn/all during its own accepted/dispatched unresolved call plus parallel siblings: actual first prepared request retains current input/fresh task/instructions, excludes the whole parent exchange, creates no successful result or duplicate effect.
- Header/create, grants/pins, seed fsync/installation, completion/input receipt and cold cuts: one stable target/seed/input; same original unknown reconciliation, no destructive rollback or changed-source regeneration. Same-ID different digest conflicts. Source/role/instruction/ACL changes across every await have current/blocked outcomes.
- Exact current-source/detached/anonymous/cached-empty/nonempty/wrong-view handling through real public executor/fork entries. New local input lies outside the committed inherited prefix.
- Qualified same-live native positives with actual original/target owned terminal and exact per-protocol requirements; forged/copied/cold/new-binding/account/route/signature/prefix/args negatives; Bedrock ambient truthful refusal. Test unconditional Codex final auth mismatch without usage calibration and actual captured credential snapshot semantics without logging credentials.
-100MiB consumed-source control where effective seed/request size follows retained items/dependencies, not consumed bodies; no whole-history streaming/R6 claim. Existing R4A body/page/fan evidence is reused where owners remain unchanged.
- Exact format10 predecessor execution refusal of literal11 ready/interrupted/header-only targets before repair/auth/transport, old-format read compatibility, actual Gateway and true CLI entry execution, affected types and normal graph/reachability with no fake consumers/exemptions.

The plan must keep a source/reader contract gate, a target-bootstrap/real-consumer gate, and an inherited-native/actual-request gate separately reviewable while recording their dependencies and withholding whole-B completion until the connected range qualifies. ## Root decisions after focused design criticism

The adjacent `design-preflight-review.md` identified concrete missing contracts. Root supplied these binding clarifications to the same focused drafter; `contracts-plan-draft.md` must define actual DTOs/callers/oracles before execution:

- N counts framed source turns, including hidden, empty and current open turns. Keep a canonical sorted/merged completed-turn interval set and total framed count; unframed prefix counts0. Inherited domain composes with local turns, while completion metadata never authorizes execution. If N>=total, preserve the old all-prefix fallback; otherwise unframed prefix is outside selection. Shared history derives child-local replacement extents from covered items, not parent raw bodies, and consumption remains monotone after summary hiding/reset/rewind.
- Ordinary atSeq follows the original first turn/end>=atSeq and post-turn suffix rule, with latest completed boundary for beyond-archive. Seed-group physical seq covering multiple virtual turns explicitly refuses ambiguous-boundary. Resolve that source boundary first, then apply CURRENT effective visibility; summaries/groups straddling it refuse, fully contained later summaries can be retained, and hidden summaries never resurrect their consumed originals.
- The in-flight input exception is a typed partition BEFORE interval union. Only input/admission/raw-prepared-context/image evidence qualifies. Any tool-call/result/dispatch edge or tool-media companion forbids this exception. Remove physical-unit association only from the derived input-observation component and preserve its relation in audit-only omitted work. Entire input/derived-context components remain together; original parent state is never relabelled closed.
- Imported exchange classification is **inherited-observation**, with explicit/legacy acceptance retained only as source observation. Local address grammar binds item/call/result/media ordinals and a common group source, all<=64UTF8 bytes. Required exact ResultEnvelope retention/catalog/media associations survive nested forks; do not infer them from wire strings. Imported records create no local pending inputs/delegations/effects; session-scope input protection remains.
- Keep original call IDs and existing conservative ambiguity guards. **No v1 callId micropruning of seed messages**: seed rendering never consults the global v1 map, and prune proposals skip inherited exchanges. Whole-group replacement/reset/summary remains supported and remeasured. Literal controls cover local/seed shared call IDs, an ineffective seed-only marker falsely counted as progress, bounded summary fallback and future replacement/rewind consumption. Prune-v2 is not a correctness prerequisite for this gate.
- Non-none semantic seed uses a first non-ignorable manifest metadata record (turn domain, omissions, dependencies) plus group records; scalar header pins counts/codec/digests. Do not place large arrays in the bounded header. Default none is exactly zero inherited records and does not project/clone parent payloads; fresh child instructions/new task remain. Non-none empty-wire observations may still require the manifest. Anonymous semantic input relations do not copy raw operational claims or need fake parent lineage.
- The concrete bootstrap API must preserve one original operation/target/token, reuse original creation metadata across retries, and transport the same recovery identity through actual RPC failures. After-ready receipt adoption never restarts an uncertain initial task. Parent terminal outcome must remain truthful when a child bootstrap is unpublished/blocked. Preserve the original child start/deadline across resolver/bootstrap awaits, even when opening generation follows the confirmed initial-input receipt.
- Native remains the live-only variant. No archived full identity tuple; an actual original accepted-object/owned-terminal association in the existing execution owner supplies live proof. Narrow verifier/constraint contracts live in llm-seam without provider-runtime importing core-agent. A real prepared union/report and request data plan survive wrappers/withOutputCap; capabilities remain host-only. Monotone pure preparation is bounded by initial native-unit count+1 and original deadline, while final-auth fallback uses only the existing bounded unsent/unobserved rebuild under the same allowance. Bedrock ambient refusal is truthful and does not trigger a new auth subsystem.
