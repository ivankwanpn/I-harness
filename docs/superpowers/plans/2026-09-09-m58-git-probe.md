# M58 執行計劃：R-B4 A — git 唯讀對照（plan().unseen）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement task-by-task.

**Goal:** `plan()` 時唯讀對照 workspace 的 git 狀態，把「日誌無法解釋的磁碟變更」以加性欄位 `unseen` 誠實列出；非 git / git 不可用 → 行為完全不變。

**Architecture:** 新 `packages/rewind/src/git-probe.ts`（注入式 exec、`rev-parse` + `status --porcelain=v1 -z`、`GIT_OPTIONAL_LOCKS=0` 唯讀、fail-soft）；`RewindServiceOptions.gitProbe?` 顯式注入（缺席＝引擎維持純日誌）；產品呼叫點（TUI embedded / CLI）以 `createGitProbeForStore` 綁定 store 目錄排除。

**Tech Stack:** TS ESM strict、vitest、Node 內建 `child_process`（零新依賴）。

**Spec:** `docs/superpowers/specs/2026-09-09-m58-git-probe-design.md`
**Global Constraints:** 唯讀（不碰 index/refs/工作區）；加性（既有欄位語意不變）；fail-soft（任何 git 失敗 → 欄位缺席，plan() 不拋）；不捏造 op；每任務 commit（分支 m58）。
