# v0.1.13 Instruction Context Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完善 AGENTS.md／CLAUDE.md 的來源、作用範圍、子代理和上下文生命週期，並讓使用者能確認實際載入內容的來源。

**Architecture:** instructions 只解析來源與產生一致快照；runtime-context 持有每 Session 的 section 與模型交付狀態；session-executor/context 組裝 main/child 和工具 target 預檢。共享唯讀 cache，不共享 child 的生效狀態。

**Tech Stack:** TypeScript、Node bounded file I/O、fs-watch、既有 Session projection／compaction、Vitest、Electron／React。

**Spec:** `docs/superpowers/specs/2026-10-13-v0.1.13-instruction-context-design.md`

## Global Constraints

- 擴充現有 instructions package；不做第二 loader、不對不同 provider 分叉政策。
- 一目錄一個 winner，AGENTS 優先 CLAUDE；scope 標籤、globals 遷移、24000 UTF-8 bytes 見 spec。
- 不實作整套 Claude memory／imports／managed rules；不自動讀取 foreign globals。
- 新目錄／事件介面和結構、事件計劃共用；現有大測試／工具腳本不拆分，只作必要驗證調整。
- 所有實作先對相應現況加有意義 RED，不能把 fixture 錯誤當產品缺陷。
- 產品程式尚未開工；以下是可執行的工作分解，未跑任何新增測試。
