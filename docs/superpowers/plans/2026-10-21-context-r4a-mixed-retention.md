## Required discriminating controls

### M1 — Shared physical budget and live configuration

Calibrate actual capture/search and both result readers first. Then fill a controlled part of the configured shared budget with genuine legacy plus managed data, including the incomplete operation. Verify both directions: managed admission counts existing legacy/index bytes; legacy capture/grant counts existing managed/pending bytes. Known refusal may leave honest recorded operation metadata; it cannot delete someone else's protected content or fabricate successful full retention. Legacy capture can admit a truthful partial prefix: distinguish full/partial/none, check originalBytes/bytes/complete plus literal prefix/digest, and do not force every no-full-fit case to return undefined. Managed quota refusal and unknown publication remain separate.

Configuration has TWO existing branches and the oracle must preserve them:

- When the lazy legacy store is open, lowering below the actual occupied physical bytes rejects, retaining the prior effective configuration and protected files.
- When legacy is unopened, accepting a lower configured limit is allowed; existing content remains and further admission must refuse. Existing authorized managed pages can still be read.

Exercise sufficient raise and safe lowering through the same live service; actual subsequent SQLite writes must use the new budget. Do not silently restore the default512MiB or enlarge quotas to pass.

Source hypothesis: legacy service mutations and managed workspace mutations have different scheduling lanes even though they measure one directory. Both admissions are supported concurrently, so after sequential positives **one deterministic mixed-admission scheduling control is mandatory**. Positively calibrate original legacy pre/post physical accounting/write boundaries and managed requireSpace/write boundaries. Delegate real filesystem/SQLite work, holding only actual asynchronous native boundaries. Never wait inside synchronous DatabaseSync work for another operation on the same thread, recursively call a queued method from its held lane, or use draining configure/clear/close as neutral barriers. Release native holds in finally before joining cleanup.

Do not label conservative refusal or rollback of only the new legacy item as a quota breach. Record fixed quota, initial/final occupancy, full/partial/refused/unknown dispositions, remaining temporary files and protected-file invariants. Report boundary-observed peaks as samples; they do not prove a global maximum over unobserved SQLite journal writes. Identify any existing documented temporary transaction allowance before classification, and do not invent an allowance to make a failing case pass.
