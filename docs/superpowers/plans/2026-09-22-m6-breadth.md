## Global Constraints

- **T2 前綴紀律**：任何注入面的改變必須尾端追加或證明不碰前綴。批 C 的 section 走 runtime-context（已是尾端追加）；批 A 不新增一般寫入幀。
- **reachability**：`bounded-writer`／`scanMentionedSkillNames`／`createSkillsSection`／`McpCatalogError`／mount handle 的新方法 —— 每一個的生產消費者在**同一個提交**。
- **`session/event` 的 append-only 不重播**：批 A/B 都不動它。
- **事件日誌是唯一真相**：批 C 的公告**是**一條日誌事件（`user/message`）；批 B 的 clientInfo **不進**日誌。
- **schema 方言 10 關鍵字**（本計畫不動任何 tool schema；批 C 若碰工具描述也不加關鍵字）。
- **唯讀先行**：每一批的第一個紅測試在動相鄰檔案之前。
