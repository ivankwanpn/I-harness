## Root Cause
The per-session chain advanced only on predecessor success, leaving queued submits pending after rejection. Durable TUI rewind was also gated on an already-loaded session, so new durable sessions never installed a recorder. Resume sessions needed one persistence mirror, and detached rewind journal writes needed a shutdown barrier. Windows PTY/runtime verification additionally relied on PATH lookup for `chcp.com`, `taskkill.exe`, and `cmd.exe`.

Final branch review found two further lifecycle faults. Embedded TUI `open()` committed a mutable session id before asynchronous assembly resolution, so reversed concurrent completions could bind the wrong assembly and low sequence numbers from the selected session were deduplicated by the previous scrollback. SDK/ACP acquired an existing session's lease but built an empty in-memory session, losing model history and appending duplicate sequence numbers. The remediation introduced transactional TUI selection plus a non-persisted `session/open` reset event, and a shared `createDurableSessionLoader` that copies restored history into a coordinator-backed live mirror. ACP `session/close` now aborts active work, disposes the one assembly, flushes, releases its lease, and removes process-local known state.

A second adversarial review found that projection-only crash recovery could still disappear on the next restart and that TUI loaded a snapshot before retaining ownership. `loadOwned()` now takes the lease before its first read, flushes same-coordinator pending writes, runs structural plus semantic repair, assigns canonical positional sequences, and uses the JSONL backend's atomic event-body replacement only when recovery changed the durable body. Writable headless, TUI, SDK/ACP, and child-session resume paths use this operation. The same review also closed overlapping ACP controller loss, post-close implicit durable reopen, release-after-flush-failure, and remote picker cold-history gaps.

The final adversarial pass then serialized the complete same-session persistence transaction (`create`/direct append/write-behind/load/owned recovery/meta update/adopt/release), rejected non-positional established sequences instead of renumbering reference-bearing history, moved JSONL repair to synced temp-file replacement with raw-header preservation, added ACP close generations, cleaned failed SDK cold-history claims, and made remote paging follow every advancing cursor until an empty page.
