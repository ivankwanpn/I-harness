# I-harness v0.1.13-rc12（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc11 的差異是**CJK token 計算與 cache 用量記錄**。

## rc12 修正

1. **CJK token 計價**：非 ASCII 原本按 UTF-8 byte 計價，中文每字 3 token，實測較 provider 上報高估約 1.8x；現在 CJK 每字 1 token（ASCII 仍 bytes/3、其他非 ASCII 維持 byte 規則）。CJK 會話不再過早壓縮。
2. **cache 用量持久化**：`context/usage` checkpoint 新增 `cacheReadTokens` / `cacheCreationTokens`，事後可核算真實輸入。
3. 沿用 rc11 的 auto-compaction fallback 與 partial-reduction 發布修正。

## 驗證

- token-meter 54/54、context-engine 98/98、core-agent context 66/66；
- 實機新 pricing：heuristic 12,692 vs provider 總量 9,938（ratio 1.28，較修正前 1.8 改善），cacheRead 9,728 已記錄。

## 其他內容（與 rc11 相同）

- 受限沙箱 shell 修正（koffi.view × Electron）；
- 大型 workspace fs-watch 啟動修正；
- legacy fork 續傳／forked child 刪除；
- 首 prompt 不誤 reload、首 write 不誤報 unseen-rules；
- 自動壓縮（unpriced replay、partial reduction）、SCL／store 切換、自動標題、搜尋；
- 未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
