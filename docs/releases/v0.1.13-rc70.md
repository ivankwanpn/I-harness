# I-harness v0.1.13-rc70（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## Gateway 重設計第一步

* gateway 在 fatal 時送出結構化 `desktop/gateway/fatal`，main 把它併入 exit 診斷；
* main 每 15 秒對 ready gateway 做 `ping`；3 秒無回應即視為 unhealthy，關閉 child 讓 supervisor 重啟；
* supervisor 在 60 秒內最多重啟 3 次（500ms／1s／1.5s backoff）；
* renderer 收到 `sdk/ready` 自動回到 online 並重抓 dashboard／queue／history。

## 實機驗證

* 正常啟動 18 秒後仍 online（health ping 沒誤判）；
* 手動 kill gateway：PID 39916 → 41580，10 秒內 UI 回到「已連線」；
* recovery 後 `session/open` 仍可用（72 events）。

未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
