# I-harness v0.1.13-rc74（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## Queue / stop

* durable input cancel 成功後仍會補一次 `session/queue/cancel`，讓 lane projection 與 optimistic row 一致；
* 停止 draft session 時，若 `session/cancel` 回 `not-found`，會 fallback 到 `desktop/session/input/cancel` 取消 running input；
* 包含 rc73 的 recovery submit retry。

## 實機驗證（fresh session）

```json
{"before":[{"text":"...","state":"running"},{"text":"B-both-cancel","state":"queued"}],
 "c1":{"cancelled":true},"c2":{"cancelled":false},
 "after":[{"text":"...","state":"running"}]}
```

B 已從 queue 移除，A 仍在執行。

未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
