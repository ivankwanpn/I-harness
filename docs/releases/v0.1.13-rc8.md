# I-harness v0.1.13-rc8（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc7 的差異是**壓縮（compaction）修正**。

## rc8 修正

1. **rewind 後無法壓縮**：replacement 驗證把 rewind 前未關閉的 turn 判定為 ambiguous；現在 `rewind/point` 會重置 open-turn 追蹤。
2. **delivery source 永久 pending**：只保留當前 generation 的非 tool 來源，收到 `agent/delivery-received` 即移除；工具交付不再阻擋摘要。
3. **錯誤映射**：replacement 驗證失敗改回 `source-unrepresentable`，不再誤報 `capacity-unavailable`。

驗證：core-session replacement/history 68/68（含新 rewind 測試）、gateway compact/auto-title/fork 4/4；實機上先前失敗的會話成功壓縮（compacted:true、summary 產生、23 個 shadowed seqs）。

## 其他內容（與 rc7 相同）

- 大型 workspace 的 fs-watch 啟動修正；
- legacy fork 續傳、forked child 刪除；
- 首個 prompt 不誤 reload、首次 write 不誤報 unseen-rules；
- SCL／store 選擇、自動標題、搜尋；
- 未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
