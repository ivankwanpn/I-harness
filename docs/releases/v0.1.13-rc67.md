## Gateway 穩定性

* gateway 程序現在會記錄 unhandled rejection，不再因背景工作（例如自動標題）的 rejected promise 直接退出；
* 子程序退出時會回報 exit code、signal 與 stderr tail，方便診斷 `subprocess-exited`；
* 包含 rc65 的 `session/open` 與 workflow 修正。

未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
