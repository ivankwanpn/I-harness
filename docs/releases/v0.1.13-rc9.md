# I-harness v0.1.13-rc9（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc8 的差異是**壓縮評估修正**。

## rc9 修正

當 prepared request 含無法定價的 replay 內容（signature／opaque continuation）時，容量評估會回 `token-cost-unavailable`，manual compaction 先前因此直接 `capacity-unavailable`。現在若 input coverage 完整，改以 `capacityFit:'no'` 繼續壓縮，不再誤擋。

驗證：把 deepseek-flash 的 contextWindow 暫時調到 26,000、三個長回合後 manual compact 成功：`compacted:true`、`outcome:"reduced-over-target"`、`publication:"committed"`、12 個 shadowed seqs 與 summary；小會話則回 `no-progress`（如實反映無可減內容）。

## 其他內容（與 rc8 相同）

- rewind 後可壓縮（open-turn reset、delivery source 追蹤）；
- 大型 workspace 的 fs-watch 啟動修正；
- legacy fork 續傳、forked child 刪除；
- 首個 prompt 不誤 reload、首次 write 不誤報 unseen-rules；
- SCL／store 選擇、自動標題、搜尋；
- 未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
