# I-harness v0.1.18

Windows x64 正式版。從 v0.1.16 升級後，可以在同一個專案下管理資料夾和 Git 工作樹，從通知回到原來的會話，也可以在上下文側欄查看目前模型還能容納多少輸入。

## 專案與設定

- 專案設定集中管理主要資料夾、其他成員資料夾與工作樹。瀏覽清單時，不需要逐一啟動每個工作區的 Gateway。專案可以建立或匯入 Git 工作樹，並從工作台查看變更與模型審查。
- 擴充功能依 MCP、插件、技能與命令分頁。可以在沒有開啟專案時管理共用設定，也能選擇資料夾，查看該處實際可用的資源及來源。「伺服器」頁則顯示本機 Gateway 與工作區連線狀態。
- 工作完成、需要處理、核准請求、等待回答與執行錯誤可分別設定桌面提示和提示音。點擊通知時，IH 會核對來源工作區與會話，再開啟對應位置。

## 會話與工作台

- 輸入框旁的上下文圓環可開啟側欄，也能展開為獨立頁面。用量會對應到該次請求、會話與模型，並區分供應商回報和本機估算。
- 上下文側欄展開時，輸入工具列依剩餘寬度排列。長模型名稱可縮短顯示，送出鍵維持靠右。深色主題改用中性炭灰，統一設定面板、正文表格與搜尋命中外框的圓角。
- 命令中心保留 Ctrl+K 快捷鍵，頂列改用獨立的命令圖示。放大鏡開啟會話搜尋，進入搜尋頁後可用同一位置的箭頭返回。搜尋框修正了圖示與首字重疊的問題。

## 執行與模型

- 開啟長會話與讀取歷史分頁時，重用已驗證的記錄，減少重複讀取。視窗隱藏後，側欄會暫停背景讀取。正常關閉或切換執行範圍會記為資訊，非預期斷線仍會提示錯誤。
- 改善 Responses、Messages 與 Chat 相容協議的串流結束、快取用量和工具結果處理。修正 xAI/Grok 在工具呼叫後的推理續接，以及 Gemini Developer API 的模型限制與工具結果處理。
