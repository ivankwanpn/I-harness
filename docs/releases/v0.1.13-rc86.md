# I-harness v0.1.13-rc86（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## Gateway 穩定性

* Gateway 以預編譯 JS 執行，不再 runtime 使用 tsx；
* 閒置 workspace gateway 會自動回收（預設 TTL 3 分鐘，可在測試用 IH_GATEWAY_IDLE_MS 覆寫）；
* 有 running／queued／tasks／interaction 的 workspace 不會被回收；
* renderer 只在目前 workspace 輪詢，避免把所有 gateway 持續喚醒；
* disconnect 後 renderer 會以 bounded exponential backoff 自動重試；
* supervisors 仍保留 3 次/60 秒重啟與健康檢查。

## 實測

* 10 個 workspace gateway 在 5 秒 TTL 測試下，23 秒後降到 1 個；
* 回到 workspace dashboard 時 gateway 重新啟動，約 1.7 秒回應；
* 10 個 gateway 的 Working Set 由約 2,989 MB 降到約 1,508 MB（compiled JS）；閒置回收後更低。

## 已知限制

* 啟動時仍會先載入所有 workspace，之後才 idle eviction；
* auto reconnect 尚未做 UI 端到端驗證；
* 仍是 per-workspace gateway，尚未單一 host。
