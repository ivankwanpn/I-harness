# I-harness v0.1.13-rc69（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## Gateway 穩定性

* workspace gateway child 意外退出時，main 會在 60 秒內最多重啟 3 次（500ms／1s／1.5s backoff）；
* renderer 收到 `sdk/ready` 後自動回到 online，重新抓 dashboard／queue／history；
* gateway 的 unhandled rejection 會記錄 stderr，不再直接讓 child 退出；
* 退出診斷包含 exit code、signal、stderr tail。

## session/open

* 單一 `desktop/session/open` 回傳 summary、tail、queue、running、queueResumable。

## 實機驗證

* 手動 kill gateway child 後，新 child 自動啟動，UI 由「連線已中斷」回到「已連線」。

未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
