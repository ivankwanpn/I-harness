# I-harness v0.1.14

Windows x64 正式版。這版更新對話、問題與操作核准介面，並改善長會話、分叉保存及執行資源的穩定性。

## 下載

- [Windows x64 安裝程式](https://github.com/ivankwanpn/I-harness/releases/download/v0.1.14/I-harness-Setup-0.1.14.exe)
- [Windows x64 可攜 ZIP](https://github.com/ivankwanpn/I-harness/releases/download/v0.1.14/I-harness-0.1.14.zip)
- [SHA256SUMS.txt](https://github.com/ivankwanpn/I-harness/releases/download/v0.1.14/SHA256SUMS.txt)
- [發佈清單與驗證結果](https://github.com/ivankwanpn/I-harness/releases/download/v0.1.14/release-manifest.json)

升級前請關閉正在執行的 I-harness。使用可攜版時，請完整解壓並執行 `I-harness/I-harness.exe`。Windows 安裝程式及可攜版未進行程式碼簽署，Windows 可能顯示未知發行者提示。

## 更新內容

- 重設問題卡、核准卡與工作區控制。問題卡保留填寫中的「其他」答案，核准卡集中顯示指令及本次操作的權限範圍。
- 生成時展開思考內容，並在可量測的回合顯示輸出 Token 速度。供應商與會話復原錯誤有更清楚的摘要與診斷資料。
- 改善 DeepSeek Flash 使用 Responses 時的思考強度與續聊。新會話會套用已設定的預設模型。
- 修正選取結果的分叉、續聊及重試。未完成的分叉會話保持隱藏，使用者封存的會話會保留封存狀態。
- 改善 Code Mode 平行工具的寫入順序、Windows 會話文件替換及關閉時的資源回收。
- 減少 Windows 封裝中只供編譯使用的檔案。安裝器會在寫入前提示過長的安裝路徑。
- 移除實驗性 Team 功能。一般子代理功能仍可使用。

**English** · Windows x64 stable release with redesigned question and approval cards, measured token throughput, DeepSeek Responses support, and fixes for session forks, Code Mode, and Windows persistence. The experimental Team feature has been removed.
