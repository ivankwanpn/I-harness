# I-harness v0.1.13-rc33（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## 變更

* 輸出截斷不再顯示成「模型回應已中斷」：truncated step 的 step/failed 不再產生誤導列，時間軸保留「輸出達到上限被截斷」outcome；
* recovery 類失敗（cleanup／drain／reconcile unresolved）會**自動修復一次**：重啟 runtime、備份 `.i-harness`、reload session，並顯示「工作區已自動修復」；失敗時保留手動按鈕；
* 測試：runtime-feedback／error-display／ipc 54/54。

## 注意

自動修復會重建 native execution state（備份保留）。
未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
