# I-harness v0.1.13-rc11（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc10 的差異是**上下文壓縮修正**。

## rc11 修正

1. **unpriced replay 不再讓自動壓縮停擺**：signature／opaque 內容使容量價格不可用時，兩個 auto gate 原本直接跳過；現在以完整 heuristic prefix 對 threshold 判斷，會啟動 soft reduction（managed 與 legacy 兩條路徑）。
2. **partial reduction 可發布**：compaction replacement 會使 candidate 回報 `fixedInput: true`，先前被 `reductionProgress` 丟棄，導致大幅縮減（實測 33k→14k）永遠不發布、最後 `no-progress`。現在 reduction 自帶 rewrites 時允許 after fixedInput，並以 `reduced-over-target` 發布。
3. **history fact 型別修正**：deliverySource 的 `deliveryKind` 以安全轉型讀取。

## 驗證
