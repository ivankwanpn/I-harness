# I-harness v0.1.3

發行日期：2026-10-10。Windows x64，Electron 44.4.5。

Desktop 與 Desktop Gateway 的版本統一為 **0.1.3**；其他 monorepo 套件維持各自版本。這個版本包含先前本機 0.1.2、0.1.3 候選版的累積改動，取代本機測試用的中間安裝包。GitHub 的前一個公開版本是 v0.1.1。

## 使用者可見的改動

- 首頁和專案會話共用側欄位置與寬度。固定展開、收合、滑鼠暫覽具有不同的版面行為，切換側欄保留目前會話及草稿。
- 「專案」進入獨立管理頁，提供搜尋、建立、編輯、釘選與開啟既有專案。移除會從資料夾選擇器自動建立專案的「開啟專案」捷徑；資料夾在建立或編輯專案時明確加入。
- 會話依已保存的專案歸屬分組；共用資料夾不會讓未分類歷史重複出現，新增會話使用所選專案的主要資料夾。
- 最近會話使用精簡列，已讀標記在原生操作完成後刷新。首頁保留清楚標示來源資料夾的批次與封存管理入口。
- 新會話輸入框位於底部；較矮及較窄視窗保留可捲動內容。修正資源搜尋框文字與圖示重疊、窄視窗跨專案開啟，以及管理對話框關閉後的焦點恢復。
- 整合先前的 Desktop 工作台、專案變更/Git 操作、Windows 執行監督與 WSL2 後端。WSL2 設定及支援範圍見 [使用指南](../wsl2.md)。
- 支援已安裝 Claude 插件的同步命令 `SessionStart` Hook 與啟動內容注入，並維持明確授權與插件內容驗證。相容範圍見 [Hooks 驗收紀錄](../audit/2026-10-10-claude-plugin-hooks-acceptance.md)。
- 發行程式名稱統一為 `I-harness`，並保留舊 `I-harness Desktop` 安裝及使用者資料的相容處理。
