# I-harness v0.1.13-rc26（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。rc26 針對「工作區卡在 writer dependency cleanup unresolved」加入復原重試。

## 變更

* 新的工作開始前，若 debt 中存在沒有 admission read 的殘留 scope，先嘗試一次精確 cleanup（settleDependencies）；成功就繼續，失敗才維持 fail-closed；
* 任務歷史的孤兒 reservation 在插入失敗時立即 close（不再等到整個 port close）；
* 子代理 spawn 的 observation 若因 dependency cleanup 失敗，先 settle 再重試一次觀察。

## 驗證

* core-session managed execution 測試 52/52；
* 被 wedge 的測試工作區：錯誤由 `Writer dependency cleanup unresolved` 變成較後段的 `Required source drain needs recovery`，代表 cleanup 已能推進；
* 全新工作區（demo3）子代理 websearch 正常完成。

## 尚未解決

同一個工作區若已有失敗寫入留下 fact-admission / source-drain recovery debt，仍會要求明確 recovery；目前沒有 UI 修復動作，只能改用新工作區。
