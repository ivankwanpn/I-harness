# I-harness v0.1.13-rc18（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc17 的差異是 **Context Mode 工具改為 direct exposure**。

## rc18 變更

1. **Context Mode 工具直接曝光**：`context_output_search`／`read`／`status` 在服務掛載時以 `exposure: 'direct'` 註冊（assembly／owned shell／managed shell 三條路徑），不再需要先 `tool_search`。
2. 修正模型「看不到工具就改用 bash」的行為；prompt 直接寫工具名即可。
3. 沿用 rc17 的 stale-source owner grant 與 managed search/read。

## 驗證

- context-output 47/47、code-final-output-process-reader 1/1；
- 全新會話 prompt 要求「不要先 tool_search」→ 模型直接呼叫 `context_output_search`（calls 只有它）。

## 其他內容（與 rc17 相同）

- managed search／read、managedResults／managedBytes；
- fixed-surface 壓縮、CJK／signature 計價、cache 記錄、partial-reduction；
- koffi.view、fs-watch、legacy fork、首 prompt／首 write、搜尋；
- 未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
