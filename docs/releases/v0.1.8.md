# I-harness v0.1.8

本版接續 **v0.1.7**，改善「檔案」工作區的瀏覽、編輯與關閉操作。Windows x64。

## 改善

- 寬側欄採檔案瀏覽器與編輯器左右分欄；窄側欄自動上下排列。瀏覽器可收合，保留搜尋內容。
- 分頁以檔名為主，完整路徑保留在提示與路徑列；資料夾使用可讀名稱。
- 每個檔案分頁都有清楚的 **×** 關閉入口，外部唯讀參考檔案也可直接關閉。介面沒有額外的批次關閉按鈕或選單。
- 關閉未儲存檔案時，可選擇儲存、保留草稿、捨棄草稿或取消。儲存失敗、外部衝突與資料夾移除時保留草稿。
- 切換分頁會維持選中分頁可見；鍵盤關閉分頁後，焦點回到仍開啟的檔案。
- 編輯器使用可用高度，檔案樹與內容各自捲動，行號隨視窗高度正確顯示。
- 區分正在確認存取範圍、讀取範圍失敗，以及資料夾確實已移出的狀態。

## 下載與更新

- [Windows 安裝版](https://github.com/ivankwanpn/I-harness/releases/download/v0.1.8/I-harness-Setup-0.1.8.exe)：先完整關閉舊版（包含系統匣），再執行安裝程式。
- [Portable ZIP](https://github.com/ivankwanpn/I-harness/releases/download/v0.1.8/I-harness-0.1.8.zip)：解壓到獨立資料夾後執行 `I-harness.exe`。
- Release 同時提供 `SHA256SUMS.txt` 與 `release-manifest.json`，記錄發行檔校驗值、來源提交及打包驗證。

## 驗證範圍

- Desktop 完整測試：**1,255 通過、3 項既有略過、0 失敗**；型別檢查與正式建置通過。
- 檔案工作區針對性測試：86 項通過。
- 真實 Workbench 元件搭配模擬資料，在深淺色、420／720／960 px 側欄及 420 px 視窗完成 26 項瀏覽器檢查與 32 張截圖。
- 瀏覽器檢查包含草稿保留、儲存失敗、延遲儲存後的焦點、外部唯讀分頁、獨立捲動與分頁自動定位。
- Windows 發行檔沿用未簽署的安裝流程，沒有自動更新服務。打包啟動驗證不等同於在使用者既有環境重新安裝。
