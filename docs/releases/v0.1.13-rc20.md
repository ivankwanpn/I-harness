# I-harness v0.1.13-rc20（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc19 的差異是 **MCP live 變更修復**。

## rc20 變更

1. **MCP 移出 plugin selection witness**：`captureOwnedGatewaySelection` 改用 `mcp.snapshot()`，不再把 MCP config 的 currentness 綁進 session selection；
2. **MCP live apply 串行化**：`createDesktopMcp.refresh` 以 chain 一次跑一個 apply，避免 save/enable 重疊；
3. **selection refresh 不再被 MCP mutation 卡住**：移除 refresh 時的 kind 限制。

## 驗證

- 既有會話進行中 `save` + `enable` 新 stdio server → **無 applyError、無 requires recovery**；
- 同一會話直接呼叫 `mcp__live10__mcp_ping` → `pong:live10`（無需重啟）；
- mcp-settings／owned-plugin-refresh-adoption／host-write-first 測試通過。

## 其他內容（與 rc19 相同）

- Context Mode／Code Context direct tools、managed search/read、stale-source grant；
- fixed-surface 壓縮、CJK／signature 計價、cache 記錄、partial-reduction；
- koffi.view、fs-watch、legacy fork、首 prompt／首 write、搜尋；
- 未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
