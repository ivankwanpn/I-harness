# I-harness v0.1.13

Windows x64 正式版。整合長會話的上下文、壓縮與大型結果保存，工具／子代理完成後續跑，AGENTS.md／CLAUDE.md 支援，以及 Windows 桌面封裝修復。

本版取代 `v0.1.13-rc.1`。舊候選版 ZIP 的 `./` 根目錄與 Windows 檔案總管不相容，可能無法解壓；請重新下載本版的安裝程式或 Portable ZIP。

## 下載與安裝

- **一般使用者建議：[Windows x64 安裝程式](https://github.com/ivankwanpn/I-harness/releases/download/v0.1.13/I-harness-Setup-0.1.13.exe)**。支援安裝目錄選擇、捷徑、升級及解除安裝。
- [Windows x64 Portable ZIP](https://github.com/ivankwanpn/I-harness/releases/download/v0.1.13/I-harness-0.1.13.zip)：完整解壓後，執行 `I-harness/I-harness.exe`。
- [SHA256SUMS.txt](https://github.com/ivankwanpn/I-harness/releases/download/v0.1.13/SHA256SUMS.txt)
- [release-manifest.json](https://github.com/ivankwanpn/I-harness/releases/download/v0.1.13/release-manifest.json)

升級前先關閉正在執行的 IH。安裝程式不刪除原有使用者會話與設定。GitHub 自動提供的 **Source code (zip)** 是原始碼，並非可執行程式包；請選擇上面列出的檔案。

目前 Windows 安裝程式未做程式碼簽章，Windows 可能顯示未知發行者提示。

## 主要調整

- 整合上下文準備、壓縮、供應商輸入與大型結果保存；保留各協議的快取與用量語義。
- 工具、Code Mode、子代理及 Team 的結果交付與事件續跑修復，包含重複通知去重、執行中停止與資源關閉。
- 子代理模型選擇與用量歸屬修復。
- AGENTS.md／CLAUDE.md 指令處理，以及 Goal／Plan、待辦與排程整合。
- 修正打包後 Gateway 的相對匯入與原生等待資產。
- 補齊桌面主程式所需的模型目錄檔，修正打包後啟動時找不到 `model-catalog.json` 的問題。
- **修正 Windows ZIP 相容性**：使用明確的 `I-harness` 根資料夾，打包時直接檢查 Windows 檔案總管能否讀取。
- Gateway 打包採用明確的來源檔清單，排除本機測試資料，避免測試狀態及過長路徑混入安裝包。
- 提供與 Portable ZIP 使用相同程式內容的 Windows 安裝程式。

## 驗證與限制

本次發佈針對打包回歸、Windows ZIP 解壓、安裝／升級／解除安裝、封裝執行環境與模型回應進行驗證。GitHub 資產的雜湊和驗證摘要另見 `release-manifest.json`。

既有主線已完成受控的上下文、結果保存、子代理模型與用量、Team 續跑／停止、指令檔與排程驗證；並非所有真實供應商帳戶、所有平台或全部 82 個套件的測試都在本次發佈重新執行。

- 效能優化與大型檔案的純拆分留待後續版本。雙子代理完整功能診斷已通過，但原本 15 秒效能目標仍未達標。
- Windows 唯讀沙箱下，部分未修改 Node／libuv 衍生程序的管線相容性仍有限制；未透過放寬權限繞過。
- 部分流程可能仍輸出暫時性的 readiness／關閉警告，並不代表所有警告均已消除。

**English:** Windows x64 stable release focused on usability. Includes context/result retention, event-driven tool and child continuation, instruction-file support, and desktop packaging repairs. Replaces the RC ZIP with an Explorer-compatible archive and adds an NSIS installer. Further performance tuning and source decomposition are deferred; verification remains scoped as documented.
