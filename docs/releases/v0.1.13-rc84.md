# I-harness v0.1.13-rc84（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## Gateway

* packaged gateway 改為預先編譯的 JS，不再在 runtime 使用 tsx／TypeScript；
* 10 個 workspace gateway 的 Working Set 由約 2,989 MB 降到約 1,508 MB；
* dashboard cold response 471ms；
* kill gateway child 後 supervisor 自動重啟，新 PID、dashboard 1,335ms 內恢復。

## Teammates

* desktop host 與 managed runtime 不再預設 mount team；
* 新 session 的 `spawn_teammate` 不可用；舊 team ledger 仍可讀。

## 已知限制

* subagent 在無 project 的新 session 會回 `Original task project scope unavailable`；這是 session 建立方式，不是本次 gateway 編譯問題。
