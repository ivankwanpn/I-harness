# I-harness v0.1.13-rc10（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc9 的差異是**受限沙箱 shell 修正**。

## rc10 修正

rc9 在 `read-only`／`workspace-write` 模式下，任何 shell 指令都會讓子程序以 NAPI fatal 崩潰（`napi_get_last_error_info`）。根因是 ACL sandbox 使用 `koffi.view`，而 `koffi.view` 在打包的 Electron runtime 會直接 abort（同樣呼叫在系統 Node 正常）。

rc10 只在非 Electron 使用 `koffi.view`：Electron 路徑省略多餘的 zero-fill（`koffi.alloc` 已清零），PROCESS_INFORMATION 改用 `koffi.decode` 逐次讀取。
