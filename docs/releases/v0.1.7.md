# I-harness v0.1.7

發行日期：2026-10-11。Windows x64，Electron 44.4.5。

來源提交：[`4d5cae25`](https://github.com/ivankwanpn/I-harness/commit/4d5cae253f55e54863ef2ca134bee94324c5c928)。[GitHub Release](https://github.com/ivankwanpn/I-harness/releases/tag/v0.1.7)
本版接續上一個公開版本 **v0.1.4**，整合期間的功能更新與修正。Windows x64，版本維持 **0.1.7**。

## 新增與改善

- **Coding Plans**：連接 ChatGPT 帳號使用 Codex 訂閱模型，在應用程式內查看帳號、額度、重置時間與可用重置卡。模型統一在「模型與提供商」管理，訂閱路由固定使用 Responses；使用重置卡仍需明確確認。
- **用量統計**：保存本機模型請求與供應商回報的 Token、快取資料；支援日期、專案、工作區、提供商及模型篩選。提供平直柱狀／折線／面積圖、活動熱力圖、模型排行和請求明細。API 費用可依明確設定的單價估算。
- **插件命令與輸入框**：`/` 選單跟隨插件安裝、啟用及卸載狀態更新；改善輸入框自動高度、焦點外觀，以及上下文用量圖示和懸浮詳情。
- **會話與捲動**：改善串流文字跟隨最新內容、手動捲到底部後恢復跟隨、會話管理介面及部分無法封存／移除的情況。
- **工具與環境診斷**：清楚說明用途與狀態，使用卡片呈現執行檔資訊，收起進階工具與角色清單，區分 Shell 設定問題和版本檢查結果。
- **整個右側邊欄**：各分頁共用圓角外框、完整邊界、間距和細圓角捲動條。
- **執行與可靠性**：修正 Windows Shell／PTY、子代理與 teammate 執行、背景工作、索引狀態及完整驗證流程相關問題；包含期間的媒體讀取與會話控制修正。

## 下載

- **一般安裝**：下載 `I-harness-Setup-0.1.7.exe`。先完整關閉舊版（包含系統匣），再執行安裝程式。
- **Portable**：將 `I-harness-0.1.7.zip` 解壓到獨立資料夾，執行 `I-harness.exe`，保留相鄰的 `resources` 等檔案。
- **校驗**：`SHA256SUMS.txt` 提供兩個發行檔的 SHA-256；`release-manifest.json` 記錄來源提交、檔案資訊與驗證範圍。

## 使用說明

- 用量統計從支援此功能的版本開始記錄；沒有保存的舊用量不會從文字推算。供應商未回報的測量維持未知，API 費用是依目前設定單價的估算，並非帳單。訂閱 Token 不代表訂閱剩餘額度。
- 帳號登入、模型與額度可用性取決於提供商。發行驗證使用離線／本機模擬資料，沒有消耗真實重置卡。
- Windows 發行檔尚未進行程式碼簽署，沒有自動更新服務。既有設定與會話資料沿用現有更新機制。

## 驗證範圍

- 全庫測試覆蓋 81/81 專案。初次完整執行在診斷頁最後文字調整期間出現 3 個 Desktop 測試預期失敗；修正後完整重跑 Desktop：1,226 通過、3 略過、0 失敗。合併這次重跑與其他未變更套件的結果，共 6,339 通過、21 略過；不將初次 `verify:all` 的 exit 1 描述成通過。
- 全庫型別檢查、6 個端到端測試檔、可達性檢查與正式建置通過。
- 用量統計、診斷頁及共用側欄通過深淺色、窄視窗、鍵盤與捲動／縮放檢查；畫面測試使用實際元件和模擬資料。
- 本版重新打包後，以本機 HTTP 模擬服務驗證實際 Responses adapter、Token／快取計算、定價與重啟保存；Portable ZIP 每個檔案均與 payload 核對，Setup 及 payload 完整性另行核對。
