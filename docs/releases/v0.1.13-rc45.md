# I-harness v0.1.13-rc45（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## Draft 會話

* `session/create` 後 gateway 立即通知側邊欄（rc44）；
* composer 建立耐久 draft 後立即呼叫 `onDraftCreated` 刷新側邊欄（rc45），即使後續套用模型或送出失敗，0 回合 draft 仍可見；
* draft 可在側邊欄選取繼續，也可封存，之後從已封存清單刪除。

未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
