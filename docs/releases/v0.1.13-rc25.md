# I-harness v0.1.13-rc25（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。rc25 修正 **子代理工具回合的 native-replay 誤拒**。

## 根因

producer witness 的 thinkingConfigId 把 budget_tokens 也算進身分；但預算會依每次請求的 output cap 被夾到 max_tokens - 1。
子代理第一個工具回合（cap 較小）記錄了 17438，回放請求（cap 較大）算出 65536，於是同一個 thinking mode 被誤判為
mode drift，本地以 native-replay 拒絕。

## 修正

* replay 只比較 **thinking mode**（與 interleaved beta）；unknown 視為相容；
* budget_tokens 不再參與 incompatible 判定（它是每次請求的生成參數，不是 replay 身分）。

## 驗證

* research 子代理：websearch succeeded → webfetch ×2 succeeded，任務 completed（不需重啟）；
* llm-anthropic 測試 169/170（prepared.test 的 1 個失敗在未套用修正時也失敗，屬既有問題）。
