# I-harness v0.1.10

本版接續 **v0.1.9**，加入模型請求自動重試、獨立錯誤提示與診斷 Log。Windows x64。

## 自動重試

- 模型請求遇到暫時性的伺服器錯誤、限流、逾時或網路中斷時，自動重試；預設最多 **5 次重試**。
- 可在 **設定 → 一般** 調整為 0–100 次；0 關閉自動重試。儲存後從下一個模型請求生效，已開啟的會話也會使用新值。明確指定重試策略的供應商範本仍保留其原有策略。
- OpenAI 回報 **Selected model is at capacity** 或對應的滿載錯誤碼時，每次至少等待 **10 秒**，並繼續使用同一模型。有效且更長的服務端等待要求優先；超過支援的 60 秒等待範圍時，結束自動恢復，不會提早重送。
- 取消會立即停止請求與等待。帳戶驗證、額度不足、無效請求、無效工具參數及憑證設定錯誤不會自動重試。
- 中斷嘗試的文字與工具呼叫仍保留在原始會話記錄中，但不作為成功回答送回模型；失敗嘗試的工具不會執行，也不會重做先前已完成的工具操作。

## 錯誤提示與 Log

- 重試顯示獨立浮動狀態與等待倒數；最終失敗顯示可關閉的小窗，從中開啟詳情與 Log。模型及網路錯誤移出輸入區；本機輸入驗證仍保留適當提示。
- **設定 → 診斷記錄（Diagnostic Log）** 支援查詢、篩選、重新整理、複製及匯出。關閉小窗或重新啟動後，仍可查看保留的記錄。
- 預設 Log 只記錄經過處理的事件、狀態碼、重試次數與識別資訊，不記錄原始提示詞、工具參數、憑證或服務端回應內容。複製及匯出使用相同資料邊界。
- 每個 Log 檔案最多 5 MiB，最多三個檔案，保留七天；查詢與匯出限定最近 1,000 筆記錄。磁碟寫入失敗不會中止模型請求。

## 驗證範圍

協議介接、重試、設定持久化與會話執行的十二個套件共 **1,508 項測試通過**；Desktop 全套 **1,306 項通過、3 項既有測試略過**。型別檢查與正式建置通過。實際介面以 420／1280 px、深／淺色主題檢查，保留 28 張畫面，驗證小窗不搶焦點、不改變輸入框尺寸，也不擋住停止按鍵。

另以本機 HTTP 服務測試串流中斷、503 恢復、滿載等待、取消及最終失敗，並檢查 Log 的重新載入、複製與匯出。最終 manifest 記錄打包核對與安裝檔內執行環境的實際測試結果。

驗證沒有呼叫真實模型服務或修改使用者會話。自動恢復無法修復上游持續故障；重試次數用盡後會保留明確提示與診斷記錄。本機 gateway 程序中斷另沿用既有恢復流程，不自動重送已接受的使用者輸入。

**English:** v0.1.10 adds bounded automatic model retries (default five, configurable), a minimum ten-second delay for OpenAI model-capacity errors, independent error/retry popups, and persistent sanitized diagnostic logs. Recovery preserves failed-attempt audit data without executing its tools or replaying earlier successful effects. Local fixtures and HTTP services verify the behavior; the release manifest records the final validation scope.
