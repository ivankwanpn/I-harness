# I-harness v0.1.13-rc41（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

* 卡片改為「代理提出問題」標頭＋問題標題；
* 選項改為原生 radio 的編號列，鍵盤可用；

* 中斷狀態改為卡內精簡 banner；
* footer 放「保留問題，稍後回答」與「送出回答／儲存回答」；
* Ctrl/Cmd+Enter 送出自訂回答。
