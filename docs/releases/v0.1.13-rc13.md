# I-harness v0.1.13-rc13（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc12 的差異是**簽章不再停用容量計算**。

## rc13 修正

1. **signature（簽章）計價**：協議簽章原本走 `opaque()`，會加入 `opaque-continuation-token-cost` 不確定性，使 estimate 變 `unknown`、admission 落入 `compatibility`（context 維度 unchecked、校準與預防性壓縮停用）。現在簽章以 bytes/2 直接計價，保留 `signature-token-cost` 但不列為不可定價。
2. 沿用 rc12 的 CJK token 計價、cache 用量記錄、自動壓縮 fallback 與 partial-reduction 發布。

## 驗證

- token-meter 55/55（含 signature 計價測試）、context-engine 98/98；
- 實機：budget 由 `estimate unknown / pressure unavailable` 變 `estimated / projected-heuristic`、`pressure known`；
- 手動壓縮：`{compacted:true, outcome:ready, publication:committed}`。

## 其他內容（與 rc12 相同）

- 受限沙箱 shell 修正（koffi.view × Electron）；
- 大型 workspace fs-watch 啟動修正；
- legacy fork 續傳／forked child 刪除；
- 首 prompt 不誤 reload、首 write 不誤報 unseen-rules；
- 自動壓縮、CJK 計價、cache 記錄、SCL／store 切換、自動標題、搜尋；
- 未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
