# I-harness v0.1.4

發行日期：2026-10-10。Windows x64，Electron 44.4.5。

本版在輸入框上方顯示會話的專案歸屬，並提供新會話的專案選擇器。Desktop 與 Desktop Gateway 版本均為 **0.1.4**；其他 monorepo 套件維持各自版本。

## 改動

- 新會話可直接在輸入框上方搜尋並選擇已保存的專案；選單顯示目前選項及主要資料夾，並提供專案管理入口。
- 選擇專案沿用該專案的主要資料夾，各專案的草稿分開保存；切換本身不會建立或移動會話。
- 已有來源資料夾的新會話可明確選擇「不在專案中工作」。初次啟動尚未選擇來源時，先選專案或進入管理頁設定。
- 既有會話只顯示後端確認的已保存歸屬，移動操作繼續使用原本管理功能。正在確認、無法確認、未分類與專案已移除有各自的顯示。
- 原生建立及送出操作進行中會鎖定專案選擇器，避免切換錯誤來源。
- 選單支援搜尋、方向鍵、Escape 與焦點恢復；標籤與輸入框相接，並處理窄視窗的選單位置。

- 新增專案情境 10 項，相關集中測試共 67 項通過；Desktop TypeScript 檢查通過。
- 最終打包程式的隔離桌面驗收 9 項通過，包括真實專案歸屬、唯讀既有標籤、搜尋、草稿往返切換、未分類狀態、窄視窗及主要資料夾路由。
