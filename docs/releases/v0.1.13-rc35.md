# I-harness v0.1.13-rc35（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## 側邊欄改進

* 管理入口只剩一組：移到側邊欄底部，不再隨每個會話群組重複；
* 新增「新會話」列：空白 draft 會出現在所屬專案／未分類群組，選取時高亮；
* 合併兩個分支動作：只保留「建立分支」，移除「建立另一個分支」；
* 有待處理訊息時「封存會話」停用並顯示提示；
* 會話 meta 不再以「· 」開頭（`· 1 回合` → `1 回合`），meta 字級 10→11px。

## 驗證

* desktop session-actions／app-selection／session-management 測試 51+16 全綠。

## 注意

未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
