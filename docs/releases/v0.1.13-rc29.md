# I-harness v0.1.13-rc29（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## 變更

* 新增「修復工作區」：`desktop/workspace/repair` 會重啟該工作區 runtime，並把 `.i-harness` 執行狀態移到 `.i-harness.bak-<timestamp>`；
* 錯誤通知在 recovery 類錯誤時顯示「修復工作區」按鈕，成功後自動 reload session；
* 沿用 rc28 的錯誤摘要與 issued-batch reconciliation。

## 驗證

* ipc repair 測試通過（runtime invalidate + `.i-harness` 備份）；
* desktop 錯誤顯示 23/23。
