# I-harness v0.1.13-rc87（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## Gateway lazy startup

* 啟動時不再對每個 workspace 查詢 navigation ownership；只載入目前 workspace。
* 實測 10 個 workspace 的 userdata：啟動 gateway 由 10 個降到 **1 個**；展開另一個專案後才變成 2 個。
* 搭配 rc86 的 idle eviction 與 compiled gateway JS。

## 其他

* renderer disconnect 自動重試（bounded backoff）；
* teammates 預設關閉。

## 已知限制

* 展開專案時才載入該 workspace 的 session；跨 workspace ownership 目前以目前 workspace 為主。
* auto reconnect 尚未做完整 UI 端到端驗證。
* 仍是 per-workspace gateway。

未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
