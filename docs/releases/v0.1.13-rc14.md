# I-harness v0.1.13-rc14（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc13 的差異是**Context Mode 讀取頁面預算修正**。

## rc14 修正

1. **Context Mode read clamp**：`context_output_read` 的 managed ref 路徑把 `maxBytes` 夾到 1024..32768；先前 maxBytes 小於 ref metadata 時會回 `unavailable:budget`，現在會回可推進的頁面（實測 maxBytes 120 → 602-byte 頁、nextOffset 602）。
2. **錯誤訊息**：`subagents/result` 的驗證錯誤改為明確說明 `maxBytes` 需在 1024..16384。

## 驗證

- context-output 41/41（result-page／service）；
- 實機：同一 65,007-byte artifact 以 maxBytes 120 可正常分頁。

## 其他內容（與 rc13 相同）

- signature 計價（容量計算保持啟用）；
- CJK token 計價、cache 用量記錄；
- 自動壓縮 fallback、partial-reduction 發布；
- 受限沙箱 koffi.view 修正、大型 workspace watch 修正；
- legacy fork 續傳／刪除、首 prompt／首 write、SCL 切換、自動標題、搜尋；
- 未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
