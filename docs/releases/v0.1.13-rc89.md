# I-harness v0.1.13-rc89（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## Gateway

* 啟動只載入目前 workspace；10 個 workspace 的 userdata 實測啟動 gateway 由 10 個降到 1 個；
* gateway 以預編譯 JS 執行，不再 runtime tsx；
* idle workspace gateway 自動回收（預設 3 分鐘 TTL）；
* renderer disconnect 自動重試，成功後不再保留 disconnect banner；
* 展開另一個專案後才 spawn 該 workspace gateway。

## Teammates

* 預設不再 mount team；舊 team ledger 仍可讀。

## 實測

* 啟動 gateway：1；
* kill gateway 後 8 秒內 online，banner 清除，gateway 重生；
* 10 個 gateway 的 Working Set：約 2,989 MB → 1,508 MB（compiled JS）。

## 已知限制

* 仍是 per-workspace gateway；
* kill 後可能短暫保留一則「請求未完成」的詳細錯誤 toast；
* 跨 workspace ownership 以目前 workspace 為主。
