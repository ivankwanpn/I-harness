# I-harness v0.1.13-rc.1 — 可用性候選版

本候選版整合長會話的上下文、壓縮與輸出保存重構，工具／子代理的事件續跑，AGENTS.md／CLAUDE.md 指令支援，以及 Windows 桌面封裝修復。這次以可用性為優先；進一步效能優化與大型檔案拆分留到後續版本。

**Windows x64，Portable ZIP，預發佈候選版。** 本次提供的 ZIP 是目前驗證過的候選包，不包含先前草稿的舊安裝程式。

## 主要調整

- 上下文準備、壓縮、供應商輸入與大型結果保存的重構主線已整合。保留各協議的輸入、快取與用量語義。
- 工具、Code Mode 與子代理沿用原本的工作與結果持有者交付結果；完成通知接入主代理續跑，重複通知不應重複執行同一輸入。
- 修正 Team 完成結果的接收、主代理續跑及停止後清理。已驗證正常完成與模型請求仍在執行時停止兩種情況。
- 子代理模型切換與用量會話歸屬通過完整受控場景驗證。
- 接入 AGENTS.md／CLAUDE.md 指令處理；排程、待辦與 Goal／Plan 介面使用相應的執行狀態與操作路徑。
- 修正 Gateway 搬入安裝包後的相對匯入問題；執行套件與工作區依賴現在使用一致的模組位置。
- 補齊已核對來源及雜湊的 Windows 原生等待資產，並修正長依賴路徑造成的 ZIP 打包失敗。

## 已知限制

- **效能仍待優化。** 原本 15 秒的雙子代理測試尚未達標；完整功能診斷約 55 秒，不當作通過該效能門檻。測試門檻未被放寬。
- 本候選版沒有重跑全部 82 個套件的完整測試／型別矩陣、所有 E2E 與跨平台／大規模驗證，因此不是全量驗收完成的正式版。
- Windows 唯讀沙箱下，部分未修改 Node／libuv 衍生程序的 pipe 相容性仍有限制；本版沒有放寬權限來繞過它。
- 部分驗證仍會輸出暫時性的 readiness／關閉警告；上述已通過的關閉場景有實際完成證據，不表示所有警告已消除。
- 大型單檔的純拆分工作延後到後續版本。
