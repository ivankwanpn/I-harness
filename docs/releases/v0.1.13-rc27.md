# I-harness v0.1.13-rc27（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## 變更（在 rc26 的 cleanup 重試之上）

* core-agent 的 settlement drain 加入 4 次有界重試（60/120/180 ms），
  讓暫時性的 reconciliation 狀態（pending write、snapshot 鎖）可以自行恢復；真正的損壞仍會回報。

## 驗證

* core-session managed execution 測試 52/52；
* 被 wedge 的工作區：錯誤由 `Required source drain needs recovery` 推進到 `Original issued write needs reconciliation`，
  代表 drain 重試有效，但 issued-write 這一層仍需要 reconciliation。

## 尚未完成

同一個工作區若留下「已發出但未安裝」的寫入，目前沒有 reconciliation API，仍只能改用新工作區。
下一步需要補：issued batch 的 verify/install 或 rollback 流程（crash consistency）。
