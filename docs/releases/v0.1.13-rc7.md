# I-harness v0.1.13-rc7（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc6 的差異是**大型 workspace 的啟動修正**。

## rc7 修正

rc6 之前的 fs-watch 以 chokidar `ignoreInitial: false` 建立 watcher，啟動時對每個既有檔案發 `add`。工作區檔案超過 4096 個時會超過事件 buffer，得到 `FS_WATCH_GAP`，instructions 永久 unavailable，CLI／桌面版在該工作區的任何回合都會以 `CONTEXT_INPUT_STALE` 拒絕（實測：CLI 在 I-harness 根目錄失敗，在 docs／demo／乾淨目錄正常）。

rc7 改為 `ignoreInitial: true`：既有檔案由 baseline walk 建立，啟動事件不再灌入。

## 驗證

- fs-watch 69/69（含新 4200 檔案回歸）；
- instructions 141/141；host-write-first／auto-title／legacy-fork 4/4；
- CLI 在 I-harness 根目錄恢復 `root-ok`。

## 其他內容（與 rc6 相同）

- legacy fork 續傳、forked child 刪除；
- 首個 prompt 不誤 reload、首次 write 不誤報 unseen-rules；
- SCL／store 選擇、自動標題、搜尋；
- 未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
