# I-harness v0.1.13-rc15（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc14 的差異是**fixed surface 下的壓縮修正**。

## rc15 修正

1. **大 fixed surface 不再讓壓縮停擺**：system prompt／tool schema 的 heuristic tokens 超過 pressure target 時，baseline 會被標成 `fixedInput`，先前 `reduceContext` 直接 block('fixed-input')，導致 soft reduction 空轉、context 停在 window 的 ~88%。
2. 現在只要仍有可縮減內容（`inputTokens - fixedTokens >= 512`）就照常摘要；`ReductionAssessment` 新增 `fixedTokens`，bridge 提供 system＋schema heuristic。
3. `reductionProgress` 在有 rewrites 時允許 before／after fixedInput，partial reduction 可照常發布。

## 驗證

- context-engine 100/100（含 fixed-surface 新測試）；
- 實機（window 22,000）：baseline 21,726 → candidate 14,843，replacement 成功發布，heuristic 19,280 → 14,869，14 回合 0 失敗。
