# I-harness v0.1.13-rc38（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## 封存與刪除

* 封存不再要求先處理 pending inputs／interactions／tasks；只阻擋執行中的回合（UI 也停用並提示先停止）；
* 封存是可逆 metadata：排隊訊息、審批、任務保留，還原後可繼續；
* 已歸檔會話的永久刪除允許丟棄 pending 狀態；執行中的工作或子會話仍會阻止；
* 刪除確認文案改為「已歸檔對話」語意。
