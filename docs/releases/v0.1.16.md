# I-harness v0.1.16

Windows x64 正式版。這版改善多工作區切換與長會話閱讀。開啟另一個專案時，原工作區的任務可以繼續執行，各自的回覆會存回所屬會話。

## 工作區與背景執行

- 同一個 Desktop 使用者設定檔中的工作區共用一個後端進程，各自保有會話、執行狀態與權限範圍。多個專案使用同一資料夾時，側欄也會共用會話清單與歸屬資料。
- 切換專案時省去背景 Git 掃描。打開「專案 Git」才會讀取變更清單，包括未追蹤的檔案。
- 首次使用工作區記憶時才開啟資料庫。遇到短暫寫鎖時，IH 會在五秒內重試，其他工作區仍可回應。若在等待時取消工具、停用記憶或關閉工作區，等待儲存的筆記會取消。
- 關閉主視窗後，背景任務可以繼續。後端確認閒置後會退出，期間也可重新開啟視窗返回工作。

## 會話與工作台

- 長會話可從最新回覆向上逐頁讀取更早的記錄，再用「回到最新內容」返回。切換或重新連線後仍能翻到離開期間新增的記錄。修正第一次向上捲動偶爾被拉回底部的問題。
- 輸入框在新對話和既有對話中都保持在工作台底部。回合結束後工作過程會自動收合，可展開查看個別工具的結果與錯誤。
- 側欄繼續以專案整理會話，可從專案列直接新增會話。設定頁會隨視窗寬度調整，工作台的工具選單依專案、會話、協作與診斷分組。
