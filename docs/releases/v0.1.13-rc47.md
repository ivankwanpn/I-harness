# I-harness v0.1.13-rc47（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## Draft 會話

* `session/create` 後 main 會通知 renderer；
* composer 建立 draft 後立即刷新；
* 側邊欄在可見時每 5 秒做一次 reconciliation，沒有 live notification 的 0 回合 draft 也會出現；
* draft 可繼續、封存、從已封存清單刪除。

未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
