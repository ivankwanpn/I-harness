# I-harness v0.1.13-rc16（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc15 的差異是 **Context Mode managed 結果可見性**。

## rc16 變更

1. **managed 用量**：`context_output_status` 新增 `managedResults`／`managedBytes`，掃描 committed managed artifacts（依 session 歸屬）。
2. **managed 搜尋（部分）**：`context_output_search` 會合併 legacy 與 managed hits（inventory → 讀頁面 → lexical 命中）；`context_output_read` 支援 `ctxv1_…` refId。
3. **失敗可見**：managed artifact 若無法授權讀取，搜尋回 `partial:true` 與 reason `managed-read-unavailable`，不再靜默。
   - 注意：desktop 的 source-generation 授權尚未接上，部分會話的 managed search 可能只看到 legacy 結果；狀態計數不受影響。
