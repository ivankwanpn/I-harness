# I-harness v0.1.13-rc34（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## 變更（對齊參考項目）

* 取消「自動修復工作區」：recovery 失敗回到**明確按鈕**，不再自動重啟 runtime（參考 DSH／OpenCode／ZCode 都只顯示失敗，不自動重置）；
* 子代理目錄載入失敗時，錯誤旁提供「重試」（與 DSH 的 load error retry 一致）；
* 子代理執行失敗仍顯示狀態＋原始錯誤（不自動修復）；
* 保留 rc32 的上下文容量顯示、rc33 的截斷標示。

## 理由

repair 是工作區層級，會重啟整個 runtime；參考項目都沒有自動做，避免中斷其他執行中的回合／子代理。

## 注意

手動「修復工作區」仍在 recovery 錯誤通知中提供（含 `.i-harness` 備份）。
未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
