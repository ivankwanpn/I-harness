# I-harness v0.1.13-rc3（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc2 的差異是**修復新會話第一個 prompt 失敗**的問題。

## rc3 修正

rc2 在新會話送出第一個 prompt 時，UI 會同時載入 history／context／work-state；這些讀取在 turn 準備 writer 時被拒絕，桌面把它誤判為 session 損壞而 reload，reload 會關閉正在執行的 turn，於是顯示 `Model request failed (model_error)`。

rc3 的修正：session-scoped 的唯讀請求（history／context／dashboard／tasks／work-state／input-state／project-state／interaction-pending／model-state／navigation-state）遇到這類暫時性拒絕時會**短暫重試**（12 次 × 150ms），不再立刻 reload；prompt 與寫入永遠不會重試。

實機驗證：在測試專案建立會話並送出 prompt 可正常完成，IPC 記錄中沒有任何 `desktop/session/reload`，診斷為 `model/connecting → model/settled`，無 `session/error`。

## 其他內容（與 rc2 相同）

- Session Commit Log（SCL）opt-in 與 store 選擇（settings／CLI flag／環境變數／host 選項）與診斷頁顯示；
- legacy 與 commit log 的會話可見性、artifacts 清理、設定保留等測試；
- 未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
