# I-harness v0.1.13-rc24（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。rc24 加入 **網頁搜尋** 與 **子代理工具權限**。

## Web search

* 新增 **DeepSeek 原生搜尋** provider：沿用模型憑證呼叫 Anthropic-compatible `/messages` 的 `web_search_20250305` server tool；
* 新增 **Tavily** provider，支援 **keyless**（無 key 也能用，有 key 則帶 Bearer）；
* 每個 assembly 只註冊一個 provider：有 `DEEPSEEK_API_KEY` 時用 DeepSeek，否則 Tavily；
* `websearch` 工具因此出現在會話工具清單（主會話與子代理皆可，取決於角色 allowlist）。

實測：主會話 `websearch("DeepSeek API pricing")` → 成功回傳 api-docs.deepseek.com 等 sources。

## 子代理工具權限

* `settings.agents.roleTools.<role>`：每個角色的完整工具 allowlist；
* 子代理頁每張角色卡新增「工具權限」群組勾選（讀取／寫入／命令／網頁／Context／Code／再生成子代理），可「重設為角色預設」；
* 在 spawn 時讀取，下一個新子代理生效；
* 實測：research 角色開啟網頁工具後，子代理回報工具清單含 `webfetch`、`websearch`。

## 已知問題（非本版造成）

* 子代理**實際呼叫工具**後，下一步模型請求會被本地驗證拒絕：`Model request rejected locally: native-replay`；
* 已用乾淨的 rc23 重現（同樣的 spawn + read 測試），因此是既有問題，不在本版修正範圍。
