這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc18 的差異是 **Code Context 工具改為 direct exposure**。

## rc19 變更

1. **Code Context 工具直接曝光**：`code_context_search`／`code_context_index`／`code_context_status` 以 `exposure: 'direct'` 註冊（host 兩處），與 Context Mode 一致，不需先 `tool_search`。
2. **開關行為**（實測）：
   - Code Context ON：直接呼叫 `code_context_search`（query FACT_PRECONDITION_STALE）→ 4 hits、partial true；
   - Code Context OFF：工具仍在，呼叫回 `TOOL_FAILED`（明確表示停用）；
   - Context Mode OFF：`context_output_status` 回 `enabled:false/state:disabled`。
