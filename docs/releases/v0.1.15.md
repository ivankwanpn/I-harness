# I-harness v0.1.15

Windows x64 正式版。這版縮短送出到顯示正文的等待，並改善長會話、大型工作區及 Gateway 重啟的穩定性。

## 更新內容

- 模型回傳首段正文時即顯示 Markdown，後續片段分批更新。回覆完成時會在同一列接上已保存的訊息，並清理停止或重試留下的預覽。
- 同一工作區內切換會話時，可以接回各自正在生成的回覆。新會話、續聊和重啟後的續聊都減少了重複準備模型請求的成本。
- 長會話會批次讀取所需的歷史紀錄，並在讀取時驗證已保存的日誌前綴。大型工作區只監看指令檔候選路徑和必要的上層目錄。
- 舊 Gateway 退出後，新進程才接手原會話目錄。閒置回收和異常退出後，可以接續已保存的會話。
- 修正 Code Mode 背景執行完成與關閉會話時的寫入競態，讓工具結果和會話紀錄能各自完成保存。
- 送出訊息會等已開始的外掛更新完成。子會話會在原始寫入順序內確認保存結果，避免正常的並行寫入中斷關閉。
- 權限卡直接呈現待核准的指令，問題卡以清楚的選項清單呈現。待處理卡片上方提供停止執行，並顯示停止進度。
- 修正部分 Node 22 版本的 Windows-1252 檔案預覽與 SQLite 初始化相容性。
