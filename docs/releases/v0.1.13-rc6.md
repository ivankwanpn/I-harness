# I-harness v0.1.13-rc6（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc5 的差異是**修復刪除 forked child**。

## rc6 修正

rc5 可以 fork 並續傳，但刪除 forked child 會回 `Original session parent unavailable`。原因是 deletion selection 把 session id 與 manifest document key（如 `session-title/<id>`）混在一起，而 legacy inventory 把整個 selection 當成 result targets，於是 `prepareSession` 收到 document key。

rc6 將 selection 分成 artifact ids 與 session ids；legacy inventory 只用 session ids 當 targets。

驗證：`host-legacy-fork-continue` 重新加入刪除斷言並通過；rc5＋修正的實機刪除 fork child 回 `{"results":[{"sessionId":"forked-session-6","ok":true}]}`。

## 其他內容（與 rc5 相同）

- legacy fork 續傳；
- 首個 prompt 不誤 reload；
- 首次 write 直接成功；
- SCL／store 選擇、可見性、artifacts 清理等；
- 未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
