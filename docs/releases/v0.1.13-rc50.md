# I-harness v0.1.13-rc50（測試建置）

這是 experiment/audit-fixes-v0.1.13 分支的未簽署、未合併測試建置（Windows x64）。

## 載入對話

* `session/history` 支援 `beforeSeq`；Desktop client 與 IPC 已完整轉發；
* 對話初次載入改為**單次 tail 請求**（最新 500 筆＋headSeq），不再先 probe 再逐頁重讀完整日誌；
* 長會話最多可少掉數十次 snapshot 請求。

## 停止／送出（沿用 rc48）

* cancel 等待上限 2.5 秒、4 秒後強制停止；
* 送出時立即清空輸入框。

## 注意

初次載入只顯示最近 500 筆；更早的歷史仍透過歷史檢視讀取。

未簽署；Windows 可能顯示 SmartScreen 警告；**不合併**。
