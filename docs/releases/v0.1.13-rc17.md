# I-harness v0.1.13-rc17（測試建置）

這是 `experiment/audit-fixes-v0.1.13` 分支的未簽署、未合併測試建置（Windows x64）。相對 rc16 的差異是 **Context Mode managed search 完成授權修正**。

## rc17 變更

1. **stale-source owner grant**：session 重啟／來源重建後，owner session 仍可讀自己的 plain managed result；process page 仍維持嚴格來源檢查（replaced reader 拒絕）。
2. **managed search 端到端**：新會話建立 >60KB 輸出 → `tool_search` 找到 `context_output_search` → 呼叫命中；重啟 app（source 變更）後仍回 1 hit、`reasons: []`。
3. **managed read**：`context_output_read`（refId=`ctxv1_…`、maxBytes 2048）回 `{"stdout":"NEEDLE_MARKER_ABC…"`、nextOffset 1534。
4. 沿用 rc16 的 `managedResults`／`managedBytes` 狀態欄位與 read 失敗 reason。
