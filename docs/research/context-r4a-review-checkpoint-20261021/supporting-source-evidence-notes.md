## Findings

### F1 — P1: current running tasks bypass cold publication qualification and infer success from a child turn

**Primary location:** `packages/subagent/src/task/recovery.ts:6–18`, especially the unconditional `tasks.terminalize(... outcome: "completed" ...)` at line18. The bypass enters at `packages/subagent/src/task/publication.ts:17–18`, where `unqualifyRestoredTask` returns when a current row has no result or no outcome. `task/registry.ts:197` calls that function for version2 rows, and the actual mount sequence at `packages/subagent/src/index.ts:330–333` subsequently qualifies, classifies, and drains notifications.

Reproducible scenario: a real current TaskRegistry has durably saved its version2 `running` row with the child SID but has not saved a terminal result or the parent's original `subagent/end`. The child has committed an assistant message and `turn/end`. Retire the original owner, restore the task document, invoke the shipping qualification/classification sequence, and drain its normal notification outbox. The legacy classifier loads the child, decides it completed, and invokes a fresh terminal transition. It does not consult original parent completion publication, and the row was never marked unqualified.

Fresh authorized probe `.tmp/r4rv-1021-01/probe.mts` used actual JSONL coordinator retirement/reopen, TaskRegistry.restore/qualify/classify, TaskResultOwner, createResultCapture, ContextOutput artifact storage and the normal notification drain. Its current-v2-running row had **zero parent `subagent/end` facts**, yet became **completed / succeeded / dispatched**, created **one new result capture**, called the terminal callback once, admitted one notification and woke once. It produced a readable artifact containing the child's terminal text. Its final COLD-01 expectation deliberately failed, native exit1; stdout/stderr, source identities and observations are preserved alongside the receipt. A version2 terminal row with an already saved result but no parent completion correctly stayed unqualified/unknown with capture/admit/wake0. A literal version1 running control retained its historical completion behavior. All seven probed product hashes were equal before/after and owners were closed.

Probe boundary: the result port is a direct trusted storage adapter of the same composition used in existing retained-task-cold tests; it proves the actual result owner can create the false artifact, not shipping project ACL or a newly executed child/model. The normal shipping restore adapter may instead return unavailable retention because it lacks the old live source binding. That still leaves the incorrect completed outcome and success notification; no unavailable descriptor makes that inferred execution fact valid.

**Impact/requirement:** violates R4A-COLD-01 and A3/A7/A8/A9: child assistant text or turn/end is expressly insufficient to certify a lost original parent result. A cold open can create a new success capture/callback/wake instead of retaining an unknown, nonreplayed observation. This is current-format qualification, not future R4C durable receiver-claim work. The old classifier already existed at BASE, but R4A introduces and claims version2's stronger publication contract and currently routes those new rows through it.

**Smallest cohesive repair:** retain explicit legacy-row provenance in the existing restore/publication owner, and qualify current unfinished/pending rows conservatively before the legacy classifier or notification drain. Do not invoke a fresh result capture or completion callback from child-only evidence. Current saved observations without a matching original parent fact must stay recovery-required/unqualified with their original bytes/ref/pins intact. Preserve the actual version1 classifier contract, original terminal-result positive/negative controls, and legal later explicit input. Add discriminators for current accepted/running/pending rows and restore/save/reopen, plus callback/admit/wake/capture0 and matching original parent-fact qualification. No new journal or execution source is needed.
