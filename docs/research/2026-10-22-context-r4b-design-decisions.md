## Root rulings

- R-B-01: Source export accepts only a source label. The exporter computes a noncircular selected-data observation digest, then the complete seed digest. Current-source observation hashes exclude their own output slot; inherited origin references are deterministically rebased. These are content observations, not source freshness/authorization. None returns before parent payload projection or hashing. Cost if wrong: mismatched provenance or duplicate capture; literal reexport/anonymous/none controls are required.
- R-B-02: Use the existing package-internal bridge pattern (`llm-seam/internal/bedrock-terminal`) for the native issue capability, with an explicit new `./internal/native-transfer-issue` export and sole production importer in core-agent execution. This is a reviewed source/API boundary, not a JavaScript sandbox. Genuine prepared-terminal identity/private payload plan is required; facade/data lookalikes cannot mint it. Final prepared execution invokes constraints once before the existing confirmation callback/receipt, issue and network. Cost if wrong: stale or mismatched native bytes may reach transport; direct-stream/derivative/copy/closed-candidate negatives are mandatory.
- R-B-03: SDK/Desktop fork wire moves to explicit invocation-capable version1 capability. Missing-token old requests refuse before creation. This intentional compatibility break is acceptable on the unshipped development range: losing a server-minted token cannot be hidden by creating another child. Cost if wrong: an old client cannot fork until upgraded; it must receive a clear unsupported outcome, not a partial target.
- R-B-04: Target project/scope is confirmed by its actual existing host owner before dependency/ready confirmation; preserve existing deletion and retrieval authority. Retention does not imply orphan access. Cost if wrong: target references may survive while unavailable for authorized reads; tests must distinguish retained bytes from current permission.
- R-B-05: Accepted format10 predecessor source exists under sealed `.tmp/r4hc-02/g/node_modules/@i-harness` and final CLI under `.tmp/r4hc-02/g/cli` (R4A product678af03d). Do not run/mutate sealed roots. Use a new qualification root containing a hash-checked copy of the required old graph and controlled literal11 fixtures. Version checks must use genuine predecessor code, not simulated current predicates. If that frozen graph cannot be safely provisioned, report the qualification gap before accepting B1.
- R-B-06: Execute B1.1 and B1.2 as one source/reader gate because new events, index scope, validation readiness, memory publication and format fence share one contract. A half reader with a public incomplete-prefix bypass is not an independently valid deliverable. Gate B1 still does not activate real fork/spawn (B2) or native transfer (B3); the causal existing fork defect remains an explicitly tracked RED until B2 switches its consumer. No false all-suite green claim.
- R-B-07: Existing checkout is the current isolated development branch, not main/master; reuse it. No new worktree or decomposition-only work. Preserve all accepted R4A source/evidence and original completion28/43. Cost if wrong: integration tasks share files; serialize writer and runtime gates and commit exact scoped ranges.
- R-B-08: Current core-session has no staged-bootstrap bridge. Add explicit `./internal/bootstrap` composition entry backed by package-private staging implementation. Its managed-state constructor is consumed only by the real persistence bootstrap owner; its atomic memory-bootstrap operation by the actual standalone child/import composition. Public `createManagedSessionState`, indexes, projection, fromJSONL and append stay ready-only. No public skip-readiness flag, second index owner or cross-package private relative import. Like the existing llm-seam internal bridge, this is a reviewed source/API boundary, not a hostile same-process sandbox. Cost if wrong: callers could expose incomplete context; public-path refusal and actual final-phase installation controls are required.

## Within-task consistency scan

Implementation-time R-B-15: reuse the existing memoryRecoveryHolds map's owner-registration evidence through a private read-only predicate to reject an already-bound empty bootstrap target. Do not add a registry or prime conversationIndexes at all owner creations, which would introduce eager validation side effects. Validate structural metadata descriptors before boundary/scalar reads. Cost if wrong: a prior owner could observe a silently replaced target, or getters could execute before validation; actual bound-empty refusal and accessor counter controls are required.

Implementation-time R-B-14: codec1 adds required omission TurnExtent, derived from the original omitted interval plus related safe input components. Without it, a nested metadata-only seed could lose unlinked omitted-work observations, while unconditional preservation would silently ignore N/completed selection. Select/rebase all omissions by the same turn-boundary policy; outside drops, straddling refuses, unframed follows the existing prefix rule. Bind extent in the omission hash and rebuild input links. Cost/tradeoff: a narrow fork can conservatively refuse an inseparable audit interval; no invented/clipped range or local execution authority. Metadata-only/nested/straddling literal controls are required.

Implementation-time R-B-12/R-B-13: fix the empty-seed hash preimage to `{kind:'none'}` and dependencies to `[]` under their existing domains, and initial input to `{input: full validated admitted event minus seq,startedAt,expiresAt}` under `ih.bootstrap.initial-input.v1`. Root independently calculated the two literal empty hashes with stock Node crypto; that is design computation, not product qualification. The source none path performs no hashing; target validation/compiler share the constants. Cost if wrong: zero-prefix or initial-input mutations could pass only matching opaque scalars; literal derivation, no-initial all-fields-absent and changed input/provenance/clock negative controls are required.

Implementation-time R-B-11: `SeedOmission.relatedInputs` uses input-only ordinal order across emitted semantic group/items; `input.omittedWork` indexes the omission table. They must be a sorted unique exact forward/reverse relation, recalculated after nested selection. These positions never denote event sequences or grant authority. Cost if wrong: omitted parent work could be associated with the wrong retained input; interleaved input/exchange and nested rebase controls are required.

Implementation-time R-B-09: the manifest DTO uses seq:number, consistent with the existing addressed SessionEvent preparation/remapper; exact runtime validation still requires seq0 and compiler always emits0. A literal0 in the union broke generic seq assignment and legitimate legacy raw-remapper test typing without adding runtime protection. No optional concrete seq or second union-only manifest schema. Cost if wrong: misplaced manifests could pass publication, so actual append/cold/public malformed-sequence controls remain mandatory.

Implementation-time R-B-10: source inspection confirmed the full index calls validateConversationEventShape/validateResultFact/validResultEnvelope for all events, traversing and encoding consumed inline values before selected capture. Use a package-private selected-source structural profile in the same index/shape owner; keep all structural/readiness checks and fully validate selected components/new output. Do not rehash old consumed seed payloads, claim whole-source integrity or mint source receipts. Full intake/append/public load/fromJSONL/target validators remain strict. Cost/tradeoff: detached caller source corruption confined to discarded payload is outside the selected-export contract; whole-document integrity is checked by the normal source-load path, not proved anew by semantic export. Consumed-envelope/seed traps, selected-malformed and public-full-validator negative controls are required. No new source authority, public readiness bypass or duplicate owner is authorized.
