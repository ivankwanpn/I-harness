## Why IF14 clones preserve the relevant compiler conclusions

Every TF_Shadow reference in the pinned amalgamations was inventoried. For ordinary-table mutations, the relevant path is `tabIsReadOnly` at A:130839/F:129419 followed by `sqlite3ReadOnlyShadowTables` at A:127828/F:126419. TF_Shadow adds a defensive authorization test. Removing that label in an ordinary clone bypasses the public authorization rejection but does **not** set isMultiWrite or mayAbort, install triggers/FKs/indexes, or make the table virtual.
