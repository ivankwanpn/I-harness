# OpenCode UI attribution

`src/renderer/vendor/opencode/Button.tsx` adapts the small/normal and
primary/secondary/ghost button API and data-attribute structure from
`D:/agent-complete/opencode-fork-private-999.0.15/packages/ui/src/components/button.tsx`
and its adjacent `button.css`. The source package and repository are MIT
licensed; its license text is preserved in this directory.

The adaptation uses a native React button and the existing public Lucide icon
set. Solid, Kobalte, OpenCode stores, provider logic and services are not
included. Colors and spacing are mapped to I-harness's ZCode-inspired tokens.
