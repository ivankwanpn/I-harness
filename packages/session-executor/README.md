# Generation lifecycle composition

The executor composes the narrow Agent generation port over the existing F1 document
writer. It does not maintain a second ledger. `ManagedAction.owner` exposes only the
actual frozen session/incarnation metadata used in receipts; those scalars confer no
authority. Real action identity, capture identity, current guards and private live
known-unsent proof remain required. A managed caller without actual owner metadata
or a supported prepared terminal refuses execution. Explicit nondurable sessions keep
their labelled local behavior and make no crash guarantee.

Service and Desktop execution capture start/expiry before acquisition, admission,
model resolution or effectful host preparation. Merely enqueueing or reading an input
does not open a running model action or resolve a model. The original received-input
owner saves raw text, images and supplemental context before those waits. A single
preparation owner records started before effectful transformation, completed content
before consumption, and atomic raw+derived promotion. Cold started-without-result
preparation is blocked/failed and never runs the command again. A known failed
unpromoted input can be cancelled without blocking later explicit input.

The wire representation deliberately retains the raw slash invocation and adds its
complete expansion as a separate framed host/plugin observation. Expansion is not a
new human request. Images remain attached only to raw admission. System notification,
schedule, delegated and ambiguous legacy inputs stay literal; a version upgrade does
not opt them into host command execution. Pending human steers prepare under the
current response's same action and deadline, including before the first response.

Ingress owns its original F1 source through turn settlement. The first Agent response
borrows its opaque action once, for the exact input/document/current controller.
Closing that response does not prematurely retire ingress settlement. Direct managed
`run`/`runAdmitted` use the same actual admission and guarded promotion. An issued
promotion whose receipt becomes uncertain retains its exact capture and original
turn-close obligation; reconciliation can settle it after Stop without granting a
model send, replaying transformation or opening another action.

Normal child initial delegation and genuinely new inbox execution are child-owned
origins opened before declared-model resolution. Resident lookup alone performs no
executable resolution and creates no action. The accepted approval-review exception
binds one opaque parent auxiliary action once to its exact child; child main, summary
and recovery all spend that one auxiliary pool. Child audit remains child-owned.
A live Code Mode cell retains its original accepted lineage after yield/normal turn
finish, while explicit Stop, termination, completion or disposal revokes new auxiliary
work. No guest data or cold scalar history can reconstruct these live capabilities.

Main/default manual action duration is 60 minutes; explicit lower caps/timeouts are
measured from the original start. Title defaults to30 seconds when absent and keeps
its configured8 seconds at the Gateway call site. Approval preserves the requested
review timeout. Direct `read_video` opens its separate media action before decode or
authentication and owns at most one audio POST; it makes no token projection or B2
attribution claim for that direct body.

Detached imports with prepared raw/derived semantic links require an empty target
already created by the seed-aware owner with exact compiler-sized prefix and truthful
source lineage. Missing/mismatched prefixes fail before import writes. Plain/empty
legacy detached imports remain supported. Convenient atomic header+seed bootstrap is
reserved for the later compiler gate; this lifecycle change does not implement it.


The headless CLI captures its original start before document acquisition. It retains
one literal raw CLI receipt through the existing received-input owner, opens only the
oldest pending input before runtime/model resolution, and borrows that generation
once through the serial executor. A recovered child-local admission keeps its exact
delegated origin and inherited observation provenance. Later queued input waits for
its own execution boundary; failure pauses that queue. The CLI resolves its effective
model policy once, with explicit policy taking precedence over mockScript defaults,
and uses it consistently for main and title. Literal CLI inputs do not gain effectful
human-host preparation. Explicit lower action constraints apply from original start.

The file-backed session query reads format8 through the same verified journal decoder
and exact header scope. Inspection/search never repair the source or import action
facts as executable permission.
