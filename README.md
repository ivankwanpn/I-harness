# I-harness

Blank AI agent starting template (TypeScript + ESM).

## Requirements

- Node.js >= 22

## Getting started

```bash
npm install
npm run check
```

## Scripts

| Script             | Purpose                                   |
|--------------------|-------------------------------------------|
| `npm test`         | Run tests with Node's built-in test runner |
| `npm run typecheck`| Type-check with `tsc --noEmit`            |
| `npm run check`    | Typecheck then run tests                  |
